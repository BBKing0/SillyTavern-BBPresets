# BBPresets

SillyTavern 第三方扩展：维护世界各方的需求、资源、行动条件与写作指南，帮助长期剧情保持因果连续，并记录用户明确表达的写作喜好。

**当前版本：v0.3.1 开发预览。已完成本地自动测试及加载官方酒馆样式的浏览器回归，真实 SillyTavern 会话、模型及跨设备接续仍待验收。**

## 功能

- 独立故事存档与 if 分支，用户默认指南可被故事指南覆盖。
- AI 读取当前世界资料，再提出 2—3 个简短问题；初始化回答总计 200 字以内。
- 世界维护与作者自我总结；自动、半自动、手动三种模式。
- 条目和段落保护、来源校验、提案差异、版本恢复、导入导出及保存失败恢复副本。
- 收藏、即时点评和批量点评；只收藏不自动发送，也不推断用户喜好。
- 默认发送新消息时整理上一完整轮；可选先维护再生成。开场白、重抽和续写不算新完整轮。
- 酒馆服务器自有 JSON 存储，支持同一账户、一次一台设备的手机与电脑顺序接续。
- 扩展栏折叠入口包含全部七个功能页；悬浮球可拖动、关闭、重置位置，本设备记住选择。
- 工作台隔离宿主全局样式，保留主题颜色并使用不透明背景；默认不展示幕后作者资料。
- 可独立使用；BB-Memory 同故事只读和存档跟随均为可选功能。

世界资料描述各方处境与行动因果，不预设用户必须走的路线。AI 只维护 BBPresets 自有资料，不改写角色卡、世界书或聊天正文。

## 安装

仓库代码上传并可访问后，在 SillyTavern 的 **扩展 → 安装扩展（Install extension）** 中填写：

```text
https://github.com/BBKing0/SillyTavern-BBPresets
```

安装后刷新页面，展开扩展设置中的 **BBPresets · 世界与写作**，选择所需功能页。先在测试聊天创建存档、配置连接，再运行初始化。若已手动安装过旧版，请按 [安装与使用说明](INSTALL.md) 更新同一份扩展，避免重复加载。

也可以直接复制整个 `SillyTavern-BBPresets` 文件夹到酒馆的 `public/scripts/extensions/third-party/` 下；`manifest.json` 必须直接位于插件目录内。此仓库就是完整的安装目录，无需 ZIP、编译或额外开发文件。

插件运行无需 Node、npm 或构建工具。详细使用方法、连接配置、存档恢复与验证步骤见 [INSTALL.md](INSTALL.md)。

## 验证状态与限制

2026-09-17：40 项 Node 自动测试通过，覆盖保护、分支、来源失效、过期异步提交、保存冲突、轮次识别和初始化。此前已在真实浏览器内用模拟酒馆点检侧栏、初始化、API 测试入口及 390px 窄屏；模拟响应不代表真实模型请求通过。

主连接维护排队到正文完成，底层请求不一定支持独立中止；独立连接要求 API 支持浏览器跨域，Key 仅保存在本设备。世界书按宿主可读能力与预算节选，不保证每次读入全部资料。BB-Memory 桥接仅支持已考察格式。

服务器接口没有原子版本比较交换（CAS），适用同一账户一次一台设备的顺序使用；换设备前等待“已保存到酒馆服务器”。导出不含全部历史快照文件，历史版本会占用服务器空间。

## 仓库内容

仓库只保留可直接发布和安装的插件文件、许可证与使用说明。开发测试、工具、历史安装包和临时产物保存在本地工作区外层，不是本插件的安装依赖。

| 路径 | 用途 |
| --- | --- |
| `manifest.json`、`index.js`、`style.css` | 酒馆安装入口与样式 |
| `core/` | 数据模型与版本存储 |
| `runtime/` | 宿主适配、维护与注入 |
| `ui/` | 作者工作台 |
| `README.md`、`INSTALL.md`、`LICENSE` | 公开说明与许可证 |
| `.gitignore` | 防止意外纳入本地凭据或临时文件 |

### 为什么使用 core / runtime / ui？

BB-Memory 主要按功能拆成根目录模块，例如存储、检索、管理器。BBPresets 按职责分层：`core/` 处理资料与版本，`runtime/` 对接酒馆和模型任务，`ui/` 管理界面。两者都使用浏览器原生 ES Modules；目录组织不同不影响酒馆安装，也不需要编译或 npm install。酒馆读取根目录 manifest.json，再加载 index.js 和 style.css，其他模块通过相对路径导入。

浮动工作台使用 Shadow DOM 隔离全局 CSS，主题变量仍从酒馆继承；扩展栏保留酒馆抽屉外观并由插件处理折叠，避免重复切换。悬浮球偏好仅是本设备 UI 配置，不属于故事资料或跨设备服务器同步。
