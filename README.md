# BBPresets

SillyTavern 的个性化作者助手。预设负责 RP 扮演；BBPresets 通过读者点评积累写作建议，维护多条故事线，并把相关资料注入正文上下文。

**当前版本：v0.5.1 开发预览。已通过本地自动测试与模拟宿主浏览器验证，真实酒馆、模型表现及跨设备接续仍待实测。**

## 功能

- **划线评**：选中或粘贴喜欢 / 不喜欢的文段并评论；支持只保存、加入批次、立即发送。默认累计 5 条已提交点评后总结，可调整阈值或提前手动发送。
- **独立作者档案**：作者偏好与点评随当前酒馆账户沿用，可新建、复制、切换和导入导出。大纲独立绑定聊天，切换大纲或跟随 BB-Memory 不更换作者。
- **多线大纲**：故事核心、神明 / 人物 / 战争 / 地区发展等故事线、当前章节和伏笔。核心方向稳定，路径随互动调整；长期 RP 不预设总终局，各线可自然收束或休眠。
- **主副模型分工**：初始化提问、补问、建纲和修订均使用酒馆主连接；点评总结可选副 API。
- **按需修订**：正常正文尾部附简短控制信息，章节名和下轮选条在本地更新；只有改纲信号或用户主动请求才额外调用主模型。取消上一轮自动提取和定时作者自总结。
- **上下文注入**：故事核心、相关大纲、关键词目录及写作建议按预算注入，可查看实际发送快照。改纲默认等待，可选择“沿用旧大纲继续”。
- **编辑与检索**：条目逐条或全部折叠 / 展开；标题、关键词和完整正文搜索；整条与局部文字保护。
- **全部提示词可编辑**：系统、初始化、策划、点评、注入和控制协议等提示词统一管理，可恢复默认、导出和导入整套配置。
- **初始化恢复**：兼容完整 JSON、代码围栏和附解释的单一 JSON；损坏 / 截断结果不应用，保留回答、失败任务和本设备响应诊断，可单独重试。
- **长期存档**：自有故事、if 分支、版本恢复、来源校验与服务器保存；支持同一云酒馆账户一次一台设备的电脑 / 手机接续。
- **可选 BB-Memory 只读**：确认同故事并启用后才读取，存档跟随单独可选。插件独立使用不需要 BB-Memory。

AI 只维护 BBPresets 自有资料，不改写角色卡、世界书、BB-Memory 或聊天正文。控制块通过自己的显示规则和发送副本过滤，原始消息保持不变。

## 安装与升级

将本目录上传到仓库后，可在酒馆 **扩展 → 安装扩展** 中填写：

```text
https://github.com/BBKing0/SillyTavern-BBPresets
```

也可将整个 `SillyTavern-BBPresets` 文件夹复制到酒馆 `public/scripts/extensions/third-party/` 下。`manifest.json` 直接位于插件目录中，无需编译、npm 或 ZIP。

升级覆盖原来的同一份扩展，完整刷新页面；不要同时安装两份入口。v0.5.0 的大纲、保护和初始化草稿保留，原用户指南成为默认作者。旧故事中的偏好与点评保留在原处，可在“个性化作者”中复制为作者；不会自动变成跨聊天的偏好，复制并选用后才注入。更早的提取 / 自总结待办继续归档停用。自定义提示词保留；旧初始化模板若仍要求生成写作偏好，请在“提示词”更新或恢复该模板默认值。

展开 **BBPresets v0.5.1**，先在测试聊天创建存档，按需配置点评总结的副 API，并确保酒馆主连接可用。完整步骤见 [INSTALL.md](INSTALL.md)。

## 验证与边界

2026-09-20：81 项 Node 测试通过；新增覆盖独立作者跨聊天、BB-Memory 跟随、晚到请求与慢加载隔离、类型保持导入导出及主模型初始化。Edge 模拟宿主验证作者新建与切换、分开的大纲与作者页面、悬浮点评选段 / 粘贴、只保存无调用及导入导出；既有初始化重试、折叠搜索和草稿、提示词编辑、控制块隐藏、无逐轮额外请求、改纲等待 / 旧纲继续也通过。原有 UI 回归覆盖官方酒馆样式、透明深浅主题、桌面和 320 / 390px 手机视口、横屏及模拟触屏。模型、服务器与对话数据均为模拟。

- 控制块隐藏依赖酒馆内置 Regex 扩展；停用时有提示。其他插件直接读取原始消息时仍可能看到控制块，BB-Memory 同用需实测。
- 主模型必须遵守尾部协议；缺失或非法控制不触发补救 API 请求，正文保留、大纲不更新，可主动修订。刷新页面会丢失尚未完成正文的本轮令牌，需重新生成或主动规划。
- 选择旧大纲时，已开始的主连接请求仍需先释放，以免与正文并发；超时会提示重发正文。普通正文的目录和控制信息仍消耗 token。
- 世界书和记忆按可读能力与预算节选，不能保证每轮全量阅读；没有任意世界书选择器或语义检索。模型的长期叙事质量需真实 RP 评估。
- 副 API 需要允许浏览器跨域；Key 仅存在本设备。系统冻结或关闭页面后无法保证请求继续。
- 服务器文件接口没有 CAS，适用于单人顺序接续。等待“已保存到酒馆服务器”再换设备。历史版本会占用空间，单档上限 400 万字符、控制记录上限 5000 条；导出不包含全部服务器快照。

仓库只包含可公开安装的插件文件与说明；测试、工具、开发记录和临时产物在本地工作区外层。`core/` 负责数据，`runtime/` 对接宿主与任务，`ui/` 提供原生折叠栏内的工作台及悬浮快捷菜单。
