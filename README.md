# BBPresets

SillyTavern 的个性化作者助手。预设负责 RP 扮演；BBPresets 通过读者点评积累写作建议，维护多条故事线，并把相关资料注入正文上下文。

**当前版本：v0.5.5 开发预览。已通过本地自动测试与模拟宿主浏览器验证，真实酒馆、模型表现及跨设备接续仍待实测。**

## v0.5.5 更新

- 大纲默认按需调用：新聊天、没有申请或 nextIds 为空时不注入大纲正文，只保留当前剧情目标和有字符上限的简短目录。取消核心常驻、前两条故事线兜底和关联条目自动展开；关键词只影响目录排序。
- 正文控制协议升为 version:2，移除章节 title。progress 表示接下来要推进的剧情目标，可跨多轮揭露、追问和回答延续；chapter:null 表示沿用，目标完成或转折时再调整。
- 普通对话默认 nextIds:[]，转折、目标收束或关键伏笔时才选少量条目。单轮默认最多调用 3 条，目录默认最多 1200 字符；可在“工具 → 设置 → 大纲注入”调整或切换完整注入。全文、目录和协议都受总字符预算限制。
- 新增独立“存档”栏目：当前档、服务器保存时间、分类计数、搜索、直接加载、改名、保存、新建空白故事 / 分支及导入导出。故事和作者独立选择；启用 BB-Memory 跟随时明确提示并禁用手动换故事入口。
- 旧记录与自定义提示词保留。旧版章节总结和激进选条不转成新目标或新调用；自定义正文模板需对照新版更新。漏回 / 非法控制后不反复复用旧选条，普通轮次不增加模型请求。

## 功能

- **划线评**：选中或粘贴喜欢 / 不喜欢的文段并评论；支持只保存、加入批次、立即发送。默认累计 5 条已提交点评后总结，可调整阈值或提前手动发送。
- **独立作者档案**：作者偏好与写作点评随当前酒馆账户沿用，可新建、复制、切换和导入导出。大纲独立绑定聊天，切换大纲或跟随 BB-Memory 不更换作者。
- **多线大纲**：故事核心、神明 / 人物 / 战争 / 地区发展等故事线、当前章节和伏笔。核心方向稳定，路径随互动调整；长期 RP 不预设总终局，各线可自然收束或休眠。
- **主副模型分工**：初始化提问、补问、建纲和常规改纲使用酒馆主连接；剧情点评与写作点评均可选择主 / 副 API。
- **按需修订**：正常正文尾部附简短控制信息，剧情目标和下轮选条在本地更新；改纲信号、用户主动要求或提交的剧情点评才触发独立改纲请求。取消上一轮自动提取和定时作者自总结。
- **上下文注入**：默认仅按明确申请注入大纲正文，剧情目标、简短目录及写作建议按预算注入，可查看实际发送快照。改纲默认等待，可选择“沿用旧大纲继续”。
- **编辑与检索**：条目逐条或全部折叠 / 展开；标题、关键词和完整正文搜索；整条与局部文字保护。
- **全部提示词可编辑**：系统、初始化、策划、点评、注入和控制协议等提示词统一管理，可恢复默认、导出和导入整套配置。
- **初始化恢复**：兼容完整 JSON、代码围栏和附解释的单一 JSON；损坏 / 截断结果不应用，保留回答、失败任务和本设备响应诊断，可单独重试。
- **长期存档**：自有故事、if 分支、版本恢复、来源校验与服务器保存；支持同一云酒馆账户一次一台设备的电脑 / 手机接续。
- **可选 BB-Memory 只读**：确认同故事并启用后才读取，存档跟随单独可选。插件独立使用不需要 BB-Memory。

AI 只维护 BBPresets 自有资料，不改写角色卡、世界书、BB-Memory 或聊天正文。控制块通过自己的显示规则和发送副本过滤，原始消息保持不变。

## 安装与升级

将本目录上传到仓库后，可在酒馆 **扩展 → 安装扩展** 中填写：

```text
https://github.com/BBKing0/SillyTavern-BBPresets
```

也可将整个 `SillyTavern-BBPresets` 文件夹复制到酒馆 `public/scripts/extensions/third-party/` 下。`manifest.json` 直接位于插件目录中，无需编译、npm 或 ZIP。

升级覆盖原来的同一份扩展，完整刷新页面；不要同时安装两份入口。v0.5.0 的大纲、保护和初始化草稿保留，原用户指南成为默认作者。旧故事中的偏好与点评保留在原处，可在“个性化作者”中复制为作者；不会自动变成跨聊天的偏好，复制并选用后才注入。更早的提取 / 自总结待办继续归档停用。自定义提示词保留；若自行修改过“正文 · 尾部控制信息”，请在提示词页对照新默认值更新并保存。旧初始化模板若仍要求生成写作偏好，请在“提示词”更新或恢复该模板默认值。

展开 **BBPresets v0.5.5**，打开测试聊天后确认自动恢复或新建的大纲，按需配置点评总结的副 API，并确保酒馆主连接可用。完整步骤见 [INSTALL.md](INSTALL.md)。

## 验证与边界

2026-09-25：111 项 Node 测试、六套 Edge 模拟宿主浏览器回归通过。新增覆盖零正文默认注入、跨轮目标延续、按需限额、完整模式、旧协议兼容、漏控制后释放旧调用、存档搜索 / 改名 / 保存 / 加载及刷新恢复。原有来源 / 分支 / 保护 / 晚到 / 并行准备回归仍通过。浏览器覆盖官方宿主样式、弹窗隔离、桌面、320 / 390px、横屏与触屏。模型、记忆检索和服务器均为模拟，真实 RP 质量与跨设备接续待用户验收。

- 控制块隐藏依赖酒馆内置 Regex 扩展；停用时有提示。其他插件直接读取原始消息时仍可能看到控制块，BB-Memory 同用需实测。
- 主模型必须遵守尾部协议；缺失或非法控制不触发补救 API 请求，正文保留、大纲不更新，可主动修订。刷新页面会丢失尚未完成正文的本轮令牌，需重新生成或主动规划。
- 选择旧大纲时，已开始的主连接请求仍需先释放，以免与正文并发；超时会提示重发正文。普通正文的目录和控制信息仍消耗 token。
- 世界书和记忆按可读能力与预算节选，不能保证每轮全量阅读；没有任意世界书选择器或语义检索。模型的长期叙事质量需真实 RP 评估。
- 副 API 需要允许浏览器跨域；Key 仅存在本设备。系统冻结或关闭页面后无法保证请求继续。
- 服务器文件接口没有 CAS，适用于单人顺序接续。等待“已保存到酒馆服务器”再换设备。历史版本会占用空间，单档上限 400 万字符、控制记录上限 5000 条；导出不包含全部服务器快照。

仓库只包含可公开安装的插件文件与说明；测试、工具、开发记录和临时产物在本地工作区外层。`core/` 负责数据，`runtime/` 对接宿主与任务，`ui/` 提供原生折叠栏内的工作台及悬浮快捷菜单。
