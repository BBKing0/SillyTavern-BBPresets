# BBPresets

SillyTavern 的个性化作者、灵感与世界任务助手：用划线评积累作者建议，保存未来素材，并围绕 NPC、世界特色和主题安排可以随互动变化的任务。

**当前版本：v0.6.1 开发预览。已完成本地实现与模拟宿主验证；真实模型、手机体验和云端设备接续仍待实测。**

## v0.6.1 更新

- 世界任务返回格式有误时保留原文与可恢复字段，在“任务”逐项指出缺失或非法字段。点击“补全返回内容（含剧透）”手动补齐并保存，无需重新请求；完整 JSON 也可编辑修正。补全仍校验保护、来源和后来修改，不会直接保存部分错误批次。
- “世界任务 → 整理已有文字”可把已有文本交给所选主 / 副 API 整理格式，只发送提供的文字与格式规则，不附带聊天、角色、世界书、记忆或作者资料。缺少的内容继续交由用户补齐。
- “工具 → 设置 → 世界任务上下文”新增正文选择：默认最近三轮（最多 6 条用户 / AI 正文，如 31—36 层），可不注入或自选 `31-36,20,22-24`。楼层号沿用酒馆实际编号；创建 / 推进均生效，独立于点评上下文轮数和记忆检索方式。
- AI 新任务想法在隔一条完整回复后弹出提醒，可调整主题与连接后批准、拒绝或稍后处理。批准前不会调用详细生成 API，拒绝后刷新不重复处理；已有任务的阶段推进沿用原识别设置。
- 正文写作指导仅注入标题与建议文字，去掉 ID、truth 等内部字段；灵感与世界任务用于回报的 ID 保留。

## v0.6.0 更新

- 世界任务创建 / 推进默认按本次主题与近期上下文检索记忆，使用 BB-Memory 的 Embedding 配置；可选全量，或让时间线、里程碑、人物、物品、记忆分别使用命中 / 全量。入口为“工具 → 设置 → 世界任务上下文”，世界任务页也提供直达按钮。
- 检索在 BBPresets 内只读执行，参考正文的向量、关键词、分类及常驻规则。Embedding 未配置或失败时明确说明关键词降级，不自动读全文；常驻人物 / 物品未命中时只给简短索引。无需先生成正文获取旧命中。
- 待确认修改继续保存在任务队列。正文先使用已提交资料，不等待审核或后台回执保存；确认后的资料供后续轮次使用。真实未释放的主 API 请求仍须等待连接空闲。
- 酒馆欢迎页与聊天未加载时自动队列安静等待；聊天就绪后恢复。手动执行需要聊天的操作仍提供明确提示。
- 创作说明用 `<BBPresets_CreativeInstructions>` 包裹。已保存模板中与旧默认完全一致的原段落在注入时补标签，其他自定义内容保留。

## v0.5.9 功能

- 新增与作者、灵感同级的**世界任务**及独立存档。每个任务保存文学性任务名、一句话简介、详细主体与下一阶段提醒；正文只注入简短提醒，详细主体供创建 / 推进请求使用。
- 用户输入主题后可选主 / 副 API 创建任务。AI 提议新世界任务默认关闭；开启后，正文只给一句触发想法，用户批准或调整后由独立请求展开。灵感 AI 新增也改为短想法触发后详细安排。
- 两类新想法都等待再完成一条 AI 回复后处理，避开最新重 roll。已有世界任务的阶段回报可选隔一条识别或生成后立即识别；达成、偏离、需调整才请求下一阶段，普通延续不额外请求。
- 灵感、作者、世界任务存档可删除，并在版本恢复中找回。默认作者位于账户配置文件中，删除它只清空作者资料，保留设置、独立存档选择、绑定和服务器历史版本。
- 在存档页分别勾选灵感、世界任务并绑定到当前 BB-Memory 槽。以后切到已绑定记忆槽时切换对应档案；未绑定记忆槽保持当前选择，作者独立。
- 正文仅接受 **version:5** 短触发与进展协议，旧 v4 回执保留历史但不接受本轮直增；新模板独立可编辑。旧故事核、大纲、初始化和改纲继续作为只读废案保留。

## 开始使用

1. 在“存档”选择灵感、世界任务、作者档。需要独立故事或 if 状态时另存并选用副本；也可按下方步骤设置记忆槽绑定。
2. 打开“世界任务”，填写“主题 / 情节期待”，选择本次生成 API，点击“生成世界任务”。格式有误时到“任务”查看缺项并补全；网络失败可重试。已有长文本可使用“整理已有文字”。
3. 正常 RP。在“工具 → 注入预览”检查标签包裹的作者、灵感与世界任务提醒；在“任务”查看详细安排请求。
4. 需要查看 / 编辑世界任务主体、保护内容或手动重新安排时，切到“剧透”显示方式。

世界任务默认每档最多 5 个使用中的任务，可设 1—50；降低上限不删除已有任务。创建与推进默认主 API，灵感详细安排也默认主 API，可分别改用副 API。世界任务下一阶段注入默认开启。

| 显示方式 | 可看到的内容 |
| --- | --- |
| 防剧透（默认） | 任务名、主体条目数及基本状态 |
| 微剧透 | 另加一句话简介 |
| 剧透 | 另加下一阶段，展开详细主体，编辑 / 保护与重新安排入口 |

显示方式控制界面可见内容；正常正文仍可收到有效任务的下一阶段提醒。任务安排可以学习名家作品的困境、结构与思想，化为本世界原创情节；不预定 user 必走路线，不把计划当作既往事实。

## 灵感与成本

灵感默认待用 20 条、每轮最多注入 3 条，用户期待优先。AI 新想法通常为空；有意义的触发最多一句，详细展开每次只新增一条，成功新增后两条 AI 回复暂停新增。修订和实际使用回报仍在本地校验，真正写出对应情节才归档。

短触发每轮随启用功能提供，但**详细安排会额外调用所选 API**：手动创建、用户批准的世界任务新想法、灵感展开、世界任务达成 / 偏离 / 调整，以及用户主动整理已有文字。手工补全不发请求。普通延续、空触发和单纯灵感使用回报不新增模型请求。主连接忙时排队；停止后保留失败任务供手动重试，不自动重发。

“工具 → 设置”的注入作者、注入灵感激发点、注入世界任务下一阶段三个开关独立。全关时正文注入为空。注入灵感条数设 0 只是不提供已有素材；完全停止该类别自动维护应关闭对应注入。

## 绑定 BB-Memory

先在 BB-Memory 选择并保存当前记忆槽，再在 BBPresets 存档页选择要使用的档案，勾选要绑定的灵感 / 世界任务，点击“绑定到当前记忆存档”。绑定只记录在 BBPresets；可解除，作者不参与跟随。

读取依据稳定角色身份与已保存槽的创建标识，不用角色数组下标或单独槽名推测身份。删除后同名重建的记忆槽需要重新绑定。当前读取支持已核对的 BB-Memory 保存格式，不是双方承诺的稳定公共桥接协议。

世界任务详细安排只读当前已保存槽，默认检索，支持全文及五类混合；灵感详细展开继续使用五类全文。材料与角色、世界书和最近上下文组合，过滤向量、来源楼层和禁止注入备注。检索会按配置额外调用一次 Embedding，全文模式不发检索请求；没有 BB-Memory 时可独立创建。缺数据、缺身份或所选资料超预算时明确停止并保留任务，不用静默节选冒充全文。

当前适配核对 BB-Memory 9.5.2 的保存格式与主要规则，独立检索不修改其设置、档案或命中计数；结果可能与正文最终预算及实体展开不同。旧无模型标识的内联向量只能按维数兼容，材料会说明；已知模型、维数或内容哈希不匹配的向量不使用。

## 安装与升级

仓库：[BBKing0/SillyTavern-BBPresets](https://github.com/BBKing0/SillyTavern-BBPresets)。本目录可复制到酒馆 `public/scripts/extensions/third-party/SillyTavern-BBPresets/`，无需编译或 ZIP。

更新同一份扩展并完整刷新，确认 **BBPresets v0.6.1**。旧灵感独立档、作者及废案保留；已有账户补入独立的世界任务正文设置，默认最近三轮。未获批准的旧 AI 新任务待办也须先批准。无需重新初始化旧故事；旧自定义模板仍可导出，正文继续使用 v5 协议。详细操作见 [INSTALL.md](INSTALL.md)。

## 验证与限制

本地 227 项 Node 回归及 Edge v061 / v060 / v059 专项通过，覆盖格式补全、无上下文整理、正文楼层选择、提议确认，以及首次只读检索、五类混合、待确认期间连续正文、冷启动和停止 / 切档；桌面 / 320 / 390px / 横屏无页面脚本错误。外层历史测试目录保留旧大纲及 v056 / v058 / v060 原件，活跃场景按新交互验证，没有用跳过代替验证。

- 模型需遵守 v5。漏回、非法 ID、阶段过期、保护冲突或切档晚到不会触发越权更新；任务的文学性、自然时机和完成度判断仍需真实 RP 验收。
- 编辑、swipe、删除来源或在触发前插入新正文会使相关 AI 变更回滚 / 停止；后来人工编辑与保护保留，发生冲突时暂停相应注入。
- 导入、另存与读取保存点保留使用历史，但剥离待处理触发，不重播旧请求。
- 存档删除是可恢复删除，服务器历史文件不清理；恢复旧档不自动改变当前选择。手动保存点不回退聊天，自动保存不覆盖手动点。
- 同一云酒馆、同一账户，一次一台设备顺序接续；换设备前等待“已保存到酒馆服务器”。本机恢复区不是跨设备同步，服务器文件接口无 CAS，不支持并发双写。
- BBPresets 不改 BB-Memory、角色卡、世界书或聊天正文，只保存自身来源 ID 等 metadata。模型控制块原文保留，显示过滤依赖酒馆内置 Regex。
- 主 API 慢响应继续等待原请求，副 API 有硬超时；停止 / 切档拒绝晚到结果，不强行清除底层主连接占用。真实宿主、手机键盘与云端接续未在当前环境测试。

本仓库只含可公开安装的插件文件与说明，测试、开发记录、历史预设和临时产物保存在外层。
