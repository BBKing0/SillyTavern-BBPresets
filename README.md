# BBPresets

SillyTavern 的个性化作者助手：用划线评积累写作建议，用一句话故事核和下一个节点维持故事方向，把灵感留到合适的时候再写。

**当前版本：v0.5.7 开发预览。已完成本地实现与模拟宿主验证，真实酒馆模型质量和云端设备接续仍待实测。**

## v0.5.7 更新

- 灵感页直接打开；切换页面不再沿用另一类条目的编辑器。悬浮球的常开划线评下方新增默认折叠的灵感区，可直接填写、保存、查看近期素材和归档。
- 初始化只从角色/用户人设、启用的世界书、明确回答和已确认 BB-Memory 槽读取材料，不发送聊天楼层正文。BB-Memory 时间线、里程碑、永久记忆逐类读取，字段缺失或必读资料超预算明确报错；其他记忆/NPC/物品仅复用可验证的正常检索命中。
- 工具 → 设置 → 正文注入，独立开关 **注入作者 / 注入故事 / 注入灵感激发点**；可单开、组合或全关。关闭保留资料，停止对应正文更新；只开作者不要求控制块，全关清空 BBPresets 注入。
- 旧排队/失败初始化任务重新构造材料，保留明确回答；主连接不裁剪响应中的角色名称。失败时显示简短错误，可展开本次响应检查。

以下 v0.5.6 能力继续保留：

- 存档可新建、切换、另存为独立存档。手动加载或新建自动转为独立模式，避免被 BB-Memory 跟随切回；不修改 BB-Memory 数据。加载失败后可以重试。
- “保存存档”建立手动保存点，自动保存不覆盖它；“读取手动保存点”恢复当时的故事核和灵感。加载前版本保留，作者独立。列表限制高度，在窗口内滚动，详情可展开。
- 新故事每条线只维护 **一句话故事核 + 下一个节点**。故事核像作品简介，揭示人物、处境、目标或变化；节点是接下来值得展开的方向，可跨多轮延续。
- 新增 **灵感激发点**：用户期待与 AI 素材随故事保存，支持编辑、保护、归档和恢复待用。默认待用上限 20 条，每轮最多注入 3 条，可调为 0—20；字符预算不足会省略。
- 正文尾部 version:3 协议可更新节点、修订灵感、报告实际使用并归档。AI 通常不新增，每轮最多一条，新增后的两轮暂停新增，重复或超限跳过。没有逐轮额外模型请求。
- 旧大纲、保护内容、自定义提示词和历史保留。“故事核 → 旧大纲资料”可请求主模型精炼转换，保护内容不动。旧模板需要对照新默认值更新。

## 使用

1. 打开测试聊天，进入“故事 → 初始化”，主模型根据资料提问并建立故事核；也可在“故事核”手动新增故事线。
2. 在“故事 → 灵感激发点”写下暂时不适合当前场景的期待，例如“以后关系合适时，想看 A 给 B 买首饰”。选择待用上限与每轮注入数量。
3. 正常 RP。节点未完成时保持不变；灵感只有正文实际写出相应情节，模型才应回报使用。只是提及、计划或铺垫不算完成。
4. 在“存档”保存、另存或读档，在“任务”查看实质修订、提案与变更前后内容，在“工具 → 注入预览”查看实际注入。

写作建议属于当前作者，跨聊天沿用；故事核、灵感及剧情点评属于故事。主连接负责初始化和常规故事修订，点评可分别选择主 / 副 API。AI 只修改 BBPresets 自有数据，不修改角色卡、世界书、BB-Memory 或聊天原文。

## 安装与升级

仓库地址：<https://github.com/BBKing0/SillyTavern-BBPresets>。可在酒馆扩展安装入口填写，或整目录复制到 `public/scripts/extensions/third-party/SillyTavern-BBPresets/`。无需编译、npm 或 ZIP。

更新同一份扩展并完整刷新，确认 **BBPresets v0.5.7**，不要同时运行两个副本。使用旧自定义模板时，到“工具 → 提示词”对照默认值更新初始化、修订、JSON 格式、正文说明及尾部控制，保存后使用 version:3。自定义内容不会静默覆盖。

旧大纲不会截断或自动丢弃。转换前按旧注入设置兼容；建立新版故事核后以新版精炼资料为准，旧条目仍可查看与恢复。作者、旧点评、保护、初始化草稿和服务器版本保留。详细操作见 [INSTALL.md](INSTALL.md)。

## 验证与限制

本地 145 项 Node 回归和八套 Edge 模拟宿主浏览器回归覆盖存档失败重试、手动保存点、分支、过期结果、灵感回滚、保护、旧协议以及桌面 / 320 / 390px、横屏和触屏。具体结果在工作区开发记录中。测试模型和文件服务器均为模拟。

- 模型需遵守 version:3；漏回或非法控制不自动补发请求。归档依据模型的使用回报，程序不能判断正文是否写得自然，真实 RP 仍需验收。
- AI 新增数量和间隔限制是上限，不是写作配额。用户期待优先，同组按创建顺序注入；未被选中的素材仍保留，没有语义检索或强制到期。
- 普通节点 / 灵感控制直接在本地校验应用；实质故事核修订沿用全自动 / 半自动 / 手动模式。整条保护禁止 AI 修改及归档；局部保护不允许 AI 改写受保护文字。
- 保存点只恢复 BBPresets 资料，不回退酒馆聊天；来源失效的资料仍会回滚或暂停注入。后来新增的保护内容不会被恢复操作覆盖。另存为保留原档保存点。
- 控制隐藏依赖内置 Regex；原始消息仍含控制块。主请求慢响应继续等待，不盲目重发；停止和切档拒绝晚到结果。
- 服务器文件接口没有 CAS，仅支持同一账户一次一台设备顺序接续。等“已保存到酒馆服务器”后再换设备；IndexedDB 恢复区不是跨设备同步。
- 导出含当前资料和变更日志，不含 API Key、全部服务器历史版本或独立保存点快照；需导出保存点时先读取它再导出。单档 400 万字符、控制记录 5000 条上限保持。

本仓库只包含可公开安装的插件文件与说明。测试、工具、历史预设和开发记录保存在本地外层工作区，不随插件上传。
