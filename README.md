# BBPresets

SillyTavern 的个性化作者与灵感助手：用划线评积累作者建议，把想看的情节和创作素材留到合适的时候再写。

**当前版本：v0.5.8 开发预览。已完成本地实现与模拟宿主验证，真实模型质量和云端设备接续仍待实测。**

## v0.5.8 更新

- **故事核 / 大纲转为废案**：移除初始化、故事线编辑、节点更新、改纲请求、故事注入及 BB-Memory 跟随入口。旧任务不再运行；旧资料在“存档 → 废案 · 旧故事核 / 大纲”只读查看与导出，原文、保护、草稿和服务器版本保留。
- **灵感升级为独立存档**，与“作者”同级。分别新建、命名、选择、复制、导入导出；灵感可手动保存与读取保存点。当前两类选择都保存在酒馆账户中，切换其中一类不更换另一类，切换聊天也沿用当前选择。
- 升级时把每个旧故事中的灵感复制为“原故事名 · 灵感”，保留待用 / 归档状态、保护、来源和相应历史。迁移可重试，不重复建档；旧故事原件不删除。首次优先选用当前聊天原先绑定故事的灵感，其余在存档列表中选择；没有对应资料时建立“默认灵感”。
- 划线评的剧情、写作两类都存入当前作者，保留各自默认 API 与分组累计。剧情点评归纳带适用范围的叙事建议，不再改纲。旧故事里的点评保留，可主动复制为作者，不自动并入现有作者。
- 正文使用 **version:4 灵感协议**，只接收灵感新增、修订与实际使用回报。旧故事协议拒绝应用；旧自定义故事模板保留但停用，新版作者 / 灵感模板独立可编辑。

## 使用

1. 在“存档”新建或选用灵感档、作者档。灵感也可在“灵感”页直接切换；写作指南和划线评在“作者”中管理。
2. 在“灵感 → 灵感激发点”新增期待，或展开悬浮球中默认折叠的灵感表单，输入后保存。
3. 正常 RP。灵感不是下轮必须完成的任务，只有正文实际写出相应情节，模型才应回报使用并归档；只是提及、计划或铺垫不算。
4. 在“工具 → 注入预览”查看实际发送的作者与灵感，在“最近状况”查看控制接收结果，在“任务”查看点评提案、失败与历史。

默认待用上限 20 条、每轮最多注入 3 条（可设 0—20），用户期待优先，同组按创建顺序。AI 每轮最多新增 1 条，新增后两轮暂停；可以关闭 AI 新增 / 修订，仍允许实际使用后归档。保护条目禁止 AI 编辑与归档。没有逐轮额外模型请求。

“工具 → 设置”保留 **注入作者 / 注入灵感激发点** 两个独立开关。只开作者不要求控制块；全关时不提供 BBPresets 正文注入。注入条数设 0 仅不提供已有素材，要完全停止灵感维护应关闭灵感注入。

## 安装与升级

仓库：[BBKing0/SillyTavern-BBPresets](https://github.com/BBKing0/SillyTavern-BBPresets)。本目录可整目录复制到酒馆 `public/scripts/extensions/third-party/SillyTavern-BBPresets/`，无需编译或 ZIP。

更新同一份扩展并完整刷新，确认 **BBPresets v0.5.8**。第一次升级等待灵感复制完成；不删除服务器存档或本机恢复数据，不同时运行两份扩展。升级无需再初始化故事核。

原自定义 `injection/control/changeContract/plotFeedback` 等旧模板保留在整套提示词导出中；新运行路径使用独立的作者 JSON 格式、剧情作者建议、作者与灵感说明和灵感控制模板，避免旧协议继续驱动大纲。已有写作点评和通用系统模板继续沿用。操作见 [INSTALL.md](INSTALL.md)。

## 验证与限制

本地 91 项 Node 测试通过；Edge 模拟宿主验证升级迁移、废案查看、两类选档、编辑、划线评、version:4 控制、导入导出、刷新持久化和桌面 / 320 / 390px / 横屏布局，无页面脚本错误。使用保存的官方宿主样式复验通过。旧大纲功能测试原样保存在外层历史测试目录，不作为现版能力验收。

- 灵感档随账户选择，不再按聊天自动建档或按 if 分支自动复制。不同故事或 if 要独立发展时，主动“另存当前灵感”并选用副本。共享同一档时归档 / 修改状态也共享。
- 主模型需遵守 version:4。漏回、非法 ID、保护冲突和过期结果不会部分应用或触发补救请求；模型对实际使用和自然时机的判断仍需真实 RP 验收。
- 编辑、swipe 或删除来源会回滚相应 AI 灵感变更；后来的人工改动与保护保留，必要时暂停注入并标记冲突。新聊天不会把其他聊天的来源视作删除。
- 保存点只恢复插件资料，不回退聊天；自动保存不覆盖手动保存点。导出含当前资料与变更历史，不含 API Key、全部服务器历史文件或独立保存点快照。旧故事原版本仍保存在服务器。
- 使用同一云酒馆服务器、同一账户，一次一台设备顺序接续。换设备前等待“已保存到酒馆服务器”；本机恢复区不是跨设备同步，服务器文件接口无 CAS，不支持并发双写。
- BBPresets 不修改 BB-Memory、角色卡、世界书或聊天正文。仅自有来源 ID 等 metadata 仍按既有方式保存；控制块由主模型随正文输出，插件仅过滤显示 / 发送副本，原文保留。
- 主 API 慢响应继续接收原请求，副 API 有硬超时；停止与切档拒绝晚到结果，不强行清除底层主连接占用。

本仓库只包含可公开安装的插件文件与说明。测试、开发记录、历史预设与临时产物保存在外层工作区。
